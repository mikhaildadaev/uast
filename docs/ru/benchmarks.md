# Benchmarks

::: info **Информация**
Лучший способ сравнить библиотеки - выполнить тесты в **вашей собственной среде** с **вашей собственной рабочей нагрузкой**. Каждый проект предъявляет уникальные требования — задержка, пропускная способность, объем памяти, сложность интеграции — и ни один тест не может учесть их все.

Рекомендую вам протестировать `uast` наряду с другими библиотеками и выбрать инструмент, который наилучшим образом соответствует вашим потребностям.
:::

## Core Performance
Эти бенчмарки измеряют стоимость построения SQL-запросов с неизменяемым AST, что гарантирует отсутствие мутаций и позволяет безопасно переиспользовать запросы для разных диалектов.
